# MoieRec Project Documentation

This directory contains project design notes, architecture decision records (ADRs), API contracts, and guides for the MoieRec movie recommendation platform.

## Documentation Index

- **`architecture.md`**: Architectural breakdown of frontend, backend API, recommender core, and data flow.
- **`api_specification.md`**: REST API endpoints, schemas, and health check definitions.
- **`setup_guide.md`**: Development environment setup, virtual environments, node package installation, and local runtime verification.
