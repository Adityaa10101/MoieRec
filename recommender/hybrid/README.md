# Hybrid Recommendation Module

## Planned Components:
- **`score_fusion.py`**: Weighted linear combinations and non-linear blending of content-based similarity scores and collaborative predicted ratings.
- **`reranker.py`**: Dynamic post-ranking adjusting for user taste controls, discovery sliders, recency, and genre diversity.
- **`explainer.py`**: Explainable AI module providing human-readable justifications (e.g. "Recommended because you enjoyed *Inception* and top rated Sci-Fi directors").
