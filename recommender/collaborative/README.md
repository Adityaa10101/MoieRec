# Collaborative Filtering Module

## Planned Components:
- **`matrix_factorization.py`**: Model architectures for Matrix Factorization (Truncated SVD / Alternating Least Squares (ALS) / Surprise/implicit models).
- **`user_based.py` / `item_based.py`**: Memory-based neighborhood collaborative approaches for comparative baselines.
- **`engine.py`**: Latent-factor based inference generator matching user latent factors with candidate item vectors.
